# 0012. 데이터 보관 정책은 향후 과제

- 상태: 채택
- 날짜: 2026-09-30

## 맥락

기본 설정(설비 5대, 1초 주기)에서 샘플은 하루 약 43만 건, 1년 약 1.58억 건이다(계산값). 보관 기간을 정하려면 조회 요구와 저장 비용 근거가 필요한데, 이 프로젝트에는 그 근거가 없다.

## 결정

- 자동 삭제·보관 정책은 두지 않는다(무기한 보관)
- 가동·공백 구간을 샘플에서 계산하는 방식(ADR 0008)을 유지하되, 향후 원본 샘플을 정리할 때 구간을 먼저 보존할 수 있도록 구간 테이블 전환을 개선안으로 남긴다

## 결과

- 장기 운영 시 저장 용량과 조회 시간이 계속 는다
- 보관 정책을 정할 때 함께 결정할 것: 보관 기간, 구간 요약 보존, 삭제 작업의 실패 처리
