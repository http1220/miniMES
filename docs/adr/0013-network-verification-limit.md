# 0013. 검증 한계: 실제 다른 네트워크 미검증

- 상태: 채택
- 날짜: 2026-09-30

## 맥락

설계는 수집기·화면·Server가 서로 다른 LAN이나 VPN으로 연결될 수 있다고 전제한다(ADR 0003, 0005, 0007). 이 전제를 실제 환경에서 검증할 별도 PC나 클라우드 VM이 없다.

## 결정

- 실제 VPN·다른 네트워크 환경은 구축하지 않는다
- 수집기↔Server, 화면↔Server 사이에 **장애 주입 프록시**를 두고 지연·단절·손실을 테스트에서 켜고 끄는 방식으로 다른 네트워크 조건을 재현한다
- 도구는 상세 설계 단계에서 Windows 환경 동작을 확인한 뒤 고른다

## 검토한 대안

- **한 PC 안의 가상 머신 두 대를 VPN으로 연결**: 같은 PC 안의 흉내라 실제 다른 네트워크의 증거가 되지 않는다

## 결과

- 원하는 실패를 원하는 때에 반복 재현할 수 있다
- **실제 다른 네트워크에서의 왕복 시간, 기준점 오차, 방화벽·NAT 동작은 검증하지 않았다.** 테스트 보고서에도 이 한계를 명시한다
